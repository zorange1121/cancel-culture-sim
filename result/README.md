# Selected experiment results

This directory contains a curated, public-facing copy of the formal experiment
results generated by this project. The original files remain unchanged under
`outputs/`.

## Included

- Formal 70-seed and held-out experiment configurations
- Aggregate summaries and paired statistical contrasts
- Robustness, integrity, and paired-randomness checks
- Run-level result tables used by the published analyses
- Main figures

## Excluded

- Research and admissions reports (`*.md`)
- Smoke-test outputs
- Single-seed diagnostic runs
- Large timestep-level raw tables
- Drafts and research-portfolio material

## Result groups

- `step1_kappa_sweep_70seeds`: topology and kappa sweep
- `step1_paired_topology_kappa_analysis`: paired topology analysis
- `step2_intervention_70seeds`: intervention strategies
- `step3_cascade_aware_70seeds`: cascade-aware intervention
- `intervention_robustness_70seeds`: robustness checks
- `information_value_frontier_final_70seeds`: information-value experiments
- `frontier_ablation_70seeds`: intervention ablation
- `nested_momentum_70seeds`: nested momentum experiments
- `early_warning_risk_intervention_heldout`: held-out early-warning evaluation
- `topology_method_interaction_70seeds`: topology-by-method interaction

All copied data files retain their original names and relative directory
structure so they can be traced back to the generating scripts.
